# Actionmental · KEYCAP 设计规范 v1

面向 Kotlin / Jetpack Compose 实现。可编辑设计源文件属于本地工作材料，保存在已忽略的 `.local/design/` 目录。

## 1. 品牌 / Logo

| 文件 | 用途 |

动效：启动时三层依次落下（间隔 60ms，位移 24dp，ease-out），呼应"依次按下"。

## 2. 色彩

见 `design-tokens.css`（浅/深两套）。硬规则：
- 朱红 #C8452B（深色 #E4653F）**只用于三类语义**：强制中的旋转状态、快捷键冲突、破坏性操作。不做装饰。
- 绿 = 服务/权限正常；琥珀 = PARTIAL / UNKNOWN / Shell 高级动作 / 待用户操作。
- 状态点：7px 圆 + 3px 同色 16% 光环。
- 背景最多两层（bg / surface），禁止渐变（键帽面例外，用于表达物理性）。
- 对比度：三级墨色 ink-mid / ink-muted / ink-faint 在卡片面上 ≥ 9 / 6.4 / 4.6 : 1，最淡一级也过 WCAG AA；琥珀作文字用时浅色主题取 #96610F。
- 列表选中态用墨色粗边 + 下沉底 + 勾选图标，不用朱红，也不只靠颜色。

## 3. 字体

UI：IBM Plex Sans + Noto Sans SC；数据/按键/技术标签：IBM Plex Mono。
双语规则：中文为主，等宽英文作技术副标（同行时中文在前，英文降为 muted）。
字号阶梯：页面标题 22 · 卡片标题 16 · 正文 14 · 次要 13 · 等宽数据 12 · 全大写标签 11（下限）；行高约 1.4 倍。

## 4. 形状与海拔

圆角：卡片 12 · 底部弹层 18 · 键帽 6 · 胶囊 20 · 图标容器 8–9。
间距走 4dp 网格：8/12/16/20；屏幕内边距 16dp；卡片内边距 16dp；列表行、按钮高 ≥ 48dp；chip 视觉 36dp、可点区域补足 48dp。
可点击的卡片与行：涟漪裁进圆角，读屏角色为按钮 / 标签页。
海拔用 **2px 硬阴影**（0 2px 0）而非模糊阴影；主按钮 3px；按下态阴影归零 + 下移 2dp。

## 4.1 自适应布局

| 窗口宽度 | 导航 | 正文 |
|---|---|---|
| < 600dp | 底部导航（5 个高频入口，选中胶囊 56×32），其余入口收在首页「更多」 | 单栏 |
| 600–840dp | 88dp 导航栏（图标 + 名字），入口可滚动以适配横屏手机 | 单栏，最宽 840dp 居中 |
| ≥ 840dp | 240dp 完整侧栏（名字 + 计数 + 键盘/Shizuku 状态） | 快捷键列表/编辑器并排；其余单栏最宽 840dp |

首页状态卡：正文 < 640dp 为 2×2，否则一行四张；同行等高。按键检测：正文 ≥ 720dp 时左右分栏（组合键 + RAW | 事件流）。

## 5. 核心组件

1. **KeyCap 键帽** — 修饰键常规面，主键朱红面，按下态压平。列表 / 录制 / 检测 / 冲突四处样式必须一致。
2. **状态卡（2×2）** — 状态点 + 中文名 + 结论 + 等宽技术值（如 uid 2000 · adb）。
3. **数据行** — 键名(mono muted) ←→ 值(mono ink)，1px 虚线分隔。
4. **事件流** — 时间戳 faint / DOWN 绿 / UP 琥珀 / MATCH 朱红 / VERIFIED 绿；仅内存 200 条。
5. **冲突弹层** — 底部 sheet：当前绑定 → 将替换为；主操作「覆盖」朱红，副操作两枚次级按钮。
6. **磁贴三态** — ACTIVE(反白) / INACTIVE(深灰) / UNAVAILABLE(虚线圈 + 琥珀说明)。禁止把不可用显示为已关闭。
7. **步骤进度条** — 8 段等分细条，已完成为 ink，未完成为 keycap-line。

## 7. 引导流程规则

- 三项能力独立：缺一项只关闭对应功能。Shizuku 可跳过 → 旋转动作与磁贴显示"不可用"。
- 每一步都显示真实检测结果（轮询），不用本地标记记录"已完成"。
- 无障碍页必须列出能力边界（读取什么 / 不会做什么）。
- 推荐预设中与系统占用冲突的项默认不勾选，勾选进入覆盖确认。
- descriptor 作为稳定设备标识保存；deviceId 不作标识。
- 引导可在 设置 › 重新运行引导 再次打开。

## 8. 状态与文案原则

- 系统状态一律来自真实查询；缓存只做性能优化。查询失败显示 UNKNOWN / 不可用，绝不回落为"已关闭"。
- 错误文案 = 发生了什么(中文一句) + 技术原因(mono) + 一个可执行动作。
- 隐私文案常驻按键检测页与设置页：仅内存处理、不记录文本输入、不联网。

## 9. 实现顺序建议

令牌 + KeyCap 组件 → Dashboard → 列表/编辑/冲突 → 按键检测 → 旋转控制 → 磁贴 → 引导流程 → 应用规则。
