# Actionmental 素材包

- `logo/`：V3 组合键堆叠 logo 全套 SVG，包含主标、反白、朱红、单色、磁贴图标、横版组合和 Android 自适应图标两层。
- `design-tokens.css`：浅色与深色设计令牌，含 KeyCap 和卡片组件样式。
- `design-spec.md`：品牌、色彩语义、字体、形状、组件、页面清单、引导规则和实现顺序。

可编辑设计源文件和体积较大的离线预览属于本地工作文件，统一放在 `.local/design/`，不会进入 Git。

字体：IBM Plex Sans / IBM Plex Mono / Noto Sans SC（均为开源，可随 App 打包）。
