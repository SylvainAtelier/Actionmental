# UI/UX 自适应优化与验证

## 设计取舍

延续 KEYCAP 视觉语言：暖灰表面、清晰文字层级、克制的硬阴影与键帽元素，不引入另一套主题或额外字体依赖。按 ui-ux-pro-max 的原生应用规则落实可读性、48dp 触控基线、语义标签、自适应和系统字体缩放。技能检索中的营销落地页结构不适用于本工具，未直接套用。

## 已落实

- 导航仍按 600 / 840dp 分档；双栏独立判断，扣除侧栏后每栏至少 360dp，并随字体放大退回单栏。
- 状态卡根据可用文字空间排成 1 / 2 / 4 列；狭窄标题栏将操作移到标题下方。
- 快捷键卡片分离组合键和动作信息，键帽、筛选和外观选项允许换行，提供可见更多菜单。搜索标签持续可见，搜索与筛选状态可恢复。
- 快捷键页面的工具区与列表共用纵向滚动，避免短窗口被固定工具区挤满。
- 检测页窄屏原始数据与事件流共用列表；阅读到事件尾部时跟随新事件，不把正在查看原始数据的用户拉走。
- 数据行允许值换行；按钮和通用列表的关键文字不再依赖单行截断。
- 所有 AmSwitch 调用必须提供本地化名称；组合键按整体朗读。共享交互组件与导航增加键盘焦点描边。
- 校准浅色与深色辅助文字；强调色实心面的文字依据亮度选择黑或白；破坏性按钮使用独立 error / onError。
- Compose 与 CSS 的间距、色值、字体说明同步；Scaffold 内边距正确消费。

## 自动验证

执行命令：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug --console=plain
```

新增回归测试：

- `AdaptiveLayoutTest`：导航断点、扣除导航后的双栏最小宽度、字体放大退回单栏、状态网格列数。
- `ThemeContrastTest`：两主题的四档正文墨色，在五种中性表面上均达到 4.5:1；默认强调色、全部灰阶及代表性色值的 onAccent 对比度达到 4.5:1。

## 验证边界

自动规则与构建通过不等同于完整的真机无障碍认证。仍建议在发布前人工覆盖：375dp 手机、横屏、平板、折叠/展开、200% 字体、中英两种语言、浅深主题、TalkBack、外接键盘 Tab 导航和系统关闭动画。主题测试没有声称验证任意自定义图片或透明背景的合成对比度。
