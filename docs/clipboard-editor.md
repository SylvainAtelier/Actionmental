# 剪贴板悬浮窗：编辑当前项

## 操作

- 长按任意记录，在菜单选择「编辑」；实体键盘可用 `Ctrl+E` 编辑当前选中项。
- 编辑页直接读取数据库全文，不用列表预览作为编辑源。读取失败不打开可保存的编辑页，避免把截断内容写回。
- 「保存」更新原记录并返回列表，不修改系统剪贴板；「保存并输入」先保存，再走现有输入流程。
- `Ctrl+Enter` / `Ctrl+S` 保存，`Ctrl+Shift+Enter` 保存并输入，`Esc` 取消。
- 返回键先收起输入法，再返回列表。返回箭头、取消、点卡片外及再次唤出面板，遇到未保存修改都会要求确认；锁屏或服务断开仍优先隐藏敏感内容。

## 界面与自适应

沿用应用的浅深色语义令牌、墨色主按钮、圆角与硬阴影；正文 16sp，保存是唯一实心主操作。来源、时间与置顶状态帮助确认正在编辑的记录，正文有常驻标签与字符计数。

按实际卡片宽度及系统字体比例切换布局：窄屏只保留「保存并输入」「保存」两个页脚按钮，取消通过顶部返回入口完成；宽屏显示取消及快捷键提示。按钮至少 48dp，标签允许两行。编辑框基准高度 96dp，正常窗口扩展填满剩余区域；横屏键盘、小窗及大字体下整页滚动兜底。输入法不接管全屏，布局避让系统栏、屏幕切口和键盘。

字段有可访问标签与焦点描边；错误说明通过礼貌播报区域提示。菜单可用 Tab、方向键及 Enter 操作。编辑页及菜单动画遵循系统动画开关。

## 保存与数据安全

- 空白正文不可保存；未修改时「保存」不可用。
- 保存期间禁用重复提交、退出按钮与正文输入。
- 数据库提交成功后才离开编辑页；失败则保留正文并显示可重试提示，不执行输入。
- 保存完成时校验仍是原窗口、原编辑会话；旧面板关闭后不会异步向其他应用输入。
- 正文、去重哈希与搜索键在同一事务更新。保留当前记录的 id、来源和使用时间；重复正文合并使用次数及置顶信息。
- 事务内先确认当前项仍存在，再合并重复项，避免编辑期间条目被清理时误删其他记录。
- 文本框关闭自动填充，并请求输入法不进行个性化学习。
